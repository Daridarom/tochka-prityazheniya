# Точка притяжения

[![GitHub Pages](https://github.com/Daridarom/tochka-prityazheniya/actions/workflows/pages.yml/badge.svg)](https://github.com/Daridarom/tochka-prityazheniya/actions/workflows/pages.yml)

Официальный информационный сайт проектной экосистемы комплексного развития территорий восточного Крыма.

Публичная версия: https://daridarom.github.io/tochka-prityazheniya/

## Что внутри

- спокойная природная визуальная система: морской графит, известняк, тёплая медь и приглушённая бирюза;
- адаптивная главная страница для компьютеров и смартфонов;
- шесть направлений работы с тематическими фотографиями;
- семь территориальных концепций, включая проект «Горизонт 45» компании ООО «СЗ „АЗГАРД“» и клубный посёлок «СКИФ»;
- расширенный раздел «Боспор» с концептуальным генпланом, зонированием и событийной программой;
- расширенный раздел «Элиос» с двумя земельными контурами, природным контекстом и сценариями туристического кластера;
- раздел «СКИФ» с инфраструктурой клубного посёлка, архитектурными референсами и сервисом управляющей компании;
- раскрывающиеся карточки с функциями, площадями и кадастровыми номерами;
- переходы на отдельный сайт «Горизонт 45» и 3D-обзор территории;
- команда проекта;
- контакты и реквизиты ООО «Точка Притяжения»;
- отдельный реестр источников в docs/research-register.md.

## Технологии

- React 19;
- Next.js 16;
- Vinext и Vite;
- TypeScript;
- Cloudflare Workers-совместимая сборка.

## Локальный запуск

Нужен Node.js версии 22.13 или новее.

Команды:

    npm ci
    npm run dev

Проверка production-сборки:

    npm run build

Публикация на GitHub Pages выполняется автоматически после обновления ветки `main`.

## Где обновлять содержание

- основной текст, проекты и команда: app/page.tsx;
- визуальный стиль и адаптивность: app/globals.css;
- изображения проектов: public/media/projects/;
- фотографии команды: public/media/team/;
- заголовок и описание для поисковых систем: app/layout.tsx;
- подтверждённые источники и редакционные заметки: docs/research-register.md.

## Важное

Проектные параметры отражают презентационные материалы и могут уточняться по мере развития проектов. Материалы сайта не являются публичной офертой.

Служебные идентификаторы платформы хостинга намеренно не публикуются. При необходимости D1/R2-привязки задаются переменными `SITES_D1_BINDING` и `SITES_R2_BINDING` в среде развёртывания.

Исходные презентации использованы только как редакционная основа и не публикуются вместе с сайтом.
